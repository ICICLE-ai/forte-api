# Contributing

The original repository for this project is [`DebarghaG/forte-api`](https://github.com/DebarghaG/forte-api). The ICICLE fork tracks its `main` branch.

- Submit changes to the project through [upstream pull requests](https://github.com/DebarghaG/forte-api/pulls).
- Report bugs and request project features through [upstream issues](https://github.com/DebarghaG/forte-api/issues).
- For changes to the ICICLE catalog metadata or the fork's CI and sync workflows, open a pull request in the [ICICLE fork](https://github.com/ICICLE-ai/forte-api/pulls).
